# Review project agents

## Comando completo
```text
COMMAND: REVISAR_AGENTES_PROJETO
MISSION: review this project's capability profile before installing or executing agents.
1. Confirm project, root, branch, HEAD and environment; reuse the recorded choice. Prefer Codex. Web/CLOUD_CODE is not Claude Code.
2. Read only relevant instructions, state, queue, decisions, design system, stack and actual permissions.
3. Search metadata in catalogo/esquadroes.json and catalogo/inventario-auditado.json. Check origin, commit/hash, license, resources, tools and acceptance tests. Inventory does not mean installed.
4. Separate software, civil engineering, CRM, dashboards, marketing, Instagram, landing pages, paid media, WhatsApp, operations, accounting, finance, people and legal. Promote the existing coordinator to Supervisor without creating competing leadership.
5. Select one primary capability and justified support only. Resolve duplicates by provenance and content. Record USE_EXISTING, ADAPT, PILOT, EXCLUDE or BLOCKED with evidence.
6. Define owner, distinct executor_id/reviewer_id, inputs, outputs, acceptance, environment, dependencies, allowed_paths, forbidden actions and budget. Source folders are not agent identities. Visual specialists cannot modify databases.
7. Map foundation, product, communication and scale to real dependencies. Do not require databases or CRM when inapplicable. Publishing and spending require explicit gates.
8. Validate the task graph, maximum three cycles and stop after two attempts without progress. Check all ten brakes in docs/harness/PRODUCTION_CONTROL.md. Without a tested sandbox, lease, budget and adapter: READY_UNATTENDED=BLOCKED.
9. Update the existing canonical project profile and state. Lessons start PROPOSED; a different reviewer accepts them. Global promotion requires a PR and publication authorization. Avoid duplicate memory documents.
10. Return domain map, included/excluded capabilities, dependencies, risks, tests and next task. Never infer permission to install, change provider, secrets, database, DNS, main, production or deploy.
OUTPUT: PROJECT, ENVIRONMENT, CLIENT, HEAD, SQUADS, SELECTED_CAPABILITIES, EXCLUDED_CAPABILITIES, EVIDENCE, BLOCKERS, APPROVAL_REQUIRED, NEXT_ACTION, RELEASE_STATUS.
```
