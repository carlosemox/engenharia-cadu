# Engenharia Cadu — entrada do site

Para iniciar um produto do zero, use P01 em CONTINUO_SUPERVISIONADO. O coordenador confere aceite, segurança, backup aplicável, checkpoint e alçada antes de carregar a próxima etapa, sem pedir outra colagem. Pedido de fase isolada continua isolado.

```text
Read https://raw.githubusercontent.com/carlosemox/engenharia-cadu/main/p/P01.md
Inicie meu produto em CONTINUO_SUPERVISIONADO. Preserve as decisões e os limites; avance somente pelas etapas autorizadas após validar cada entrega.
```
