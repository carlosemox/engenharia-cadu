Entornos y agentes

Elija el entorno de desarrollo y defina el papel de cada agente antes de escribir código.

Entornos

  • Terminal: CLI, Git, scripts y pruebas.
  • Aplicación del ordenador/Mac: IDE o aplicación local, edición interactiva y revisión visual.
  • Cloud Code: VS Code, JetBrains o Cloud Shell para Cloud Run, Kubernetes, GKE y APIs de Google Cloud.

Enrutamiento

  • Codex: coordinación, integración y revisión final.
  • Gemini: pair programming, asistencia de Google y revisión localizada.
  • Antigravity: tareas agentic, navegador, artefactos y ejecución aislada.

Coordinación: un único ejecutor escribe en cada archivo o rama a la vez. El paralelismo exige un worktree/rama separada, entregable propio, diff y pruebas.
