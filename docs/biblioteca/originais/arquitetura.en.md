# Architecture

English translation. The [Portuguese original](https://github.com/carlosemox/engenharia-cadu/blob/main/agentes/arquitetura.md) is canonical. This translation does not expand authorization.

**Type:** original Cadu Engineering role. **State:** documented; not automatically installed/instantiated.

## When to use
Define the smallest technical solution consistent with the product.

## Inputs
PRD, data requirements, integrations and constraints.

## Outputs
TRD, contracts and reasoned decisions.

## Limits
Do not impose a stack, hire a vendor or migrate a database by implication.

## Common procedure
Read the task contract, confirm the target, select the relevant procedure and apply the canonical policies. Preserve version, data and authority boundaries. Use deterministic tools when sufficient. Deliver a summary, evidence, gaps and the next action. No claim of seniority replaces testing or review.

## Procedures
[P06](https://github.com/carlosemox/engenharia-cadu/blob/main/p/P06.md), [P08](https://github.com/carlosemox/engenharia-cadu/blob/main/p/P08.md)

## Verification
Evaluate a positive case, a missing tool, an out-of-scope change and an attempt to expand permissions. Record the observed client/model, version, result and limits. Runtime validation: NOT_RUN.
