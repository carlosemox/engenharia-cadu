# Incidentes

Nenhum incidente de produção observado neste lote. Falha de teste não será classificada como incidente de produção.

Registrar ID, tarefa, tentativa, snapshot, sintoma, evidência, impacto, owner, contenção, próximo passo e estado. Duas tentativas sem progresso: REPEATED_FAILURE; bloquear a tarefa e continuar a independente. Efeito externo incerto exige reconciliação, nunca retry cego.
