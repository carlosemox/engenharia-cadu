Development environments and agents

Choose the development environment and define each agent's role before writing code.

Environments

  • Terminal: CLI, Git, scripts and tests.
  • Computer/Mac application: Local IDE or application, interactive editing and visual review.
  • Cloud Code: VS Code, JetBrains or Cloud Shell for Cloud Run, Kubernetes, GKE and Google Cloud APIs.

Routing

  • Codex: coordination, integration and final review.
  • Gemini: pair programming, Google assistance and localized review.
  • Antigravity: agentic tasks, browser, artifacts and isolated execution.

Coordination: one executor writes to each file or branch at a time. Parallelism requires a separate worktree/branch, its own deliverable, diff and tests.
