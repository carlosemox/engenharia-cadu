Development environments and agents

Choose the development environment and define each agent's role before writing code.

Ambientes

  • Terminal: CLI, Git, scripts e testes.
  • Aplicativo do computador/Mac: IDE, edição interativa e revisão visual.
  • Cloud Code: VS Code, JetBrains ou Cloud Shell para Cloud Run, Kubernetes, GKE e APIs Google Cloud.

Roteamento

  • Codex: coordenação, integração e revisão final.
  • Gemini Code Assist/Gemini CLI: pair programming, assistência Google e revisão localizada.
  • Antigravity: tarefas agentic multi-etapas, navegador, artefatos e execução isolada.

Um único executor escreve em cada arquivo ou branch por vez. Paralelismo exige worktree/branch separado, entregável próprio, diff e testes.
