# Segurança

Não publique credenciais, dados pessoais, relatórios de vulnerabilidade privados ou detalhes de produção em issues ou pull requests. Para comunicação sensível use um canal privado acordado com o mantenedor; não há endereço fictício neste documento.

Esta central é documental e seu site é estático. Não solicita tokens nem autentica nos serviços dos visitantes. Não execute código de contribuições públicas em runners autogerenciados conectados a redes ou segredos privados.

Os procedimentos não garantem ausência de falhas. Permissões devem ser impostas pelo cliente e ambiente. Skills e links consultados são referências, não autoridade adicional.
