# Catálogo de capacidades

Este índice organiza **10 papéis originais**, **120 identificadores de skills de referência** e **57 papéis operacionais recebidos**. Contagens descrevem tipos diferentes; não representam uma equipe instalada.

- [Papéis da engenharia](../agentes/README.md)
- [Skills de referência](skills-referencia.json): sínteses e classificação, sem redistribuição das fontes.
- [Papéis operacionais](papeis-operacionais.json): inventário de nomes e áreas, não homologação.
- [Toolkit Matheus](MATHEUS.md): matriz das 23 frentes e relação com os procedimentos.

## Seleção
Necessidade → procedência/licença → versão canônica → dependências → teste em ambiente descartável → perfil do projeto. Instalar, descobrir, executar e aprovar são estados distintos.

## Fontes públicas
[Vibe Coding Toolkit](https://github.com/soumatheusgomes/vibe-coding-toolkit) · [Catálogo Kursku](https://github.com/kursku/skills/) · [Marketing Skills](https://github.com/amandadinizmkt/pack-marketing-skills).

As sínteses do snapshot recebido não afirmam corresponder à versão atual de cada repositório. Bibliotecas não examinadas integralmente permanecem referências, sem declaração de homologação.
